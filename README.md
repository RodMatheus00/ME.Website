# ME.Website

Repositório dedicado à publicação da **Política de Privacidade** do aplicativo Sistema Pessoal.

## URL pública

https://rodmatheus00.github.io/ME.Website/

Esta URL pode ser informada no campo “Privacy policy URL” do LinkedIn Developers.

## Escopo

Este repositório publica **somente** a página estática da política de privacidade. Não contém código operacional, APIs, bancos de dados nem arquivos de configuração sensíveis.

## Segurança

- Nunca adicione credenciais, tokens, Client ID/Secret ou arquivos `.env` a este repositório.
- Não inclua scripts, analytics, cookies ou recursos de terceiros na página publicada.

## Deploy

O site é publicado automaticamente pelo **GitHub Actions** (GitHub Pages) a cada push na branch `main`, ou via execução manual do workflow.
